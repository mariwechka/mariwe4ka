# Портфолио — Mariwechka

Персональный сайт-портфолио фриланс-дизайнера на трёх языках (RU / EN / AZ).
Статический генератор на Node.js без зависимостей: из текстов и данных собираются готовые HTML-страницы.

## Быстрый старт

```bash
cd portfolio
node build.js                 # собрать сайт в папку dist/
cd dist && python3 -m http.server 8000   # открыть http://localhost:8000
```

Готовый сайт — папка `dist/`. Её можно открыть двойным кликом по `dist/ru/index.html`
или загрузить на любой статический хостинг (Netlify, Vercel, GitHub Pages, Cloudflare Pages).

## Что нужно заменить перед публикацией

| Где | Что |
|---|---|
| `src/config.js` → `name` | Имя или псевдоним (сейчас «Mariwechka», взят из вашего ника) |
| `src/config.js` → `siteUrl` | Адрес сайта после публикации — нужен для SEO, sitemap и Open Graph |
| `src/config.js` → `tools` | Инструменты на странице «Обо мне» — оставьте только те, которыми пользуетесь |
| `src/config.js` → `available` | `true` — «Открыта для новых проектов», `false` — «Сейчас в работе» |
| `src/i18n.js` → `about.intro`, `about.introMore` | Тексты о себе в [квадратных скобках] на всех трёх языках |
| `src/i18n.js` → `about.approach` | Черновик принципов работы — перепишите своими словами |
| Фото на странице «Обо мне» | См. ниже |

После любых правок запустите `node build.js` ещё раз.

## Как добавить проект

1. Подготовьте картинки и выполните:
   ```bash
   python3 tools/images.py my-project cover.png screen1.png screen2.png
   ```
   Скрипт сожмёт их в WebP двух размеров и зарегистрирует в `src/images.json`.
2. В `src/projects.js` скопируйте любой объект проекта, поменяйте `slug`, тексты (`{ ru, en, az }`), категории и блоки.
3. `node build.js`.

**Карточка** в сетке: `card.size` — `xl`, `tall`, `m` или `l`; `card.tone` — цвет подложки.
**Страница проекта** собирается из блоков, поэтому каждый кейс выглядит по-своему:
`lead` (крупный тезис), `facts` (цифры), `image`, `pair`, `scroll` (длинный скриншот в окне),
`phones`, `strip` (горизонтальная лента), `grid-note`, `quote`, `text`.
`hero`: `image`, `type` или `split`. `theme`: свои цвета страницы.

**Категории** (`graphic`, `web`, `uiux`, `branding`, `identity`, `3d`, `digital-art`) переведены в `src/i18n.js` → `categories`.
Фильтр на странице «Работы» показывает только те категории, в которых есть проекты.

## Фотография на странице «Обо мне»

Сейчас там оформленное место под фото. Чтобы поставить снимок:
`python3 tools/images.py about portrait.jpg`, затем в `src/templates/pages.js` (функция `about`)
замените блок `<div class="photo__slot">…</div>` на `${img(page, 'about/portrait', 'Ваше имя')}`.

## Структура

```
build.js                 сборка: страницы × языки, sitemap.xml, robots.txt, 404
src/config.js            имя, контакты, адрес сайта, языки
src/i18n.js              все тексты интерфейса на RU / EN / AZ
src/projects.js          проекты: тексты, категории, блоки кейсов
src/images.json          размеры картинок (заполняется tools/images.py)
src/templates/           layout (каркас, шапка, контакты), components (карточки), pages (страницы)
assets/css/main.css      дизайн-система и все стили
assets/js/main.js        основа: переходы, меню, копирование, фильтр, письмо-конструктор
assets/js/motion.js      слой анимации (GSAP, ScrollTrigger, Lenis, canvas)
assets/js/vendor/        gsap, ScrollTrigger, lenis
tools/images.py          оптимизация картинок
dist/                    готовый сайт
```

## Анимация

- `assets/js/motion.js` — весь слой движения на **GSAP + ScrollTrigger** и плавной прокрутке **Lenis**
  (библиотеки лежат в `assets/js/vendor/`, сайт не зависит от внешних CDN).
- Первый экран: генеративное поле точек на canvas с линзой вокруг курсора и «дышащей» ультрамариновой каплей;
  толщина букв имени зависит от расстояния до курсора.
- Заставка при первом визите за сеанс, многополосная шторка с названием раздела при переходах.
- Манифест: слова проявляются при прокрутке, картинки-«пилюли» внутри строки.
- Работы на главной — горизонтальная галерея, закреплённая на экране, с параллаксом и контурными номерами.
- Раскрытие картинок по маске, параллакс, счётчики цифр, 3D-наклон карточек, магнитные кнопки,
  «перемешивание» букв в меню, вращающийся бейдж, зерно плёнки, курсор с подписями.
- Если включено «уменьшить движение» или библиотеки не загрузились, сайт работает без анимаций и всё видно.

## Что уже есть

- Отдельные адреса для каждого языка (`/ru/`, `/en/`, `/az/`) с `hreflang`, canonical, Open Graph, JSON-LD, sitemap.
- Корневой `index.html` открывает язык, выбранный в прошлый раз, иначе язык браузера.
- Переключатель языка ведёт на ту же страницу на другом языке.
- Копирование почты и Telegram с уведомлением; конструктор письма открывает почтовое приложение с готовым текстом.
- Адаптивные картинки (`srcset`, WebP, lazy loading), alt-описания.
- Анимации отключаются при системной настройке «уменьшить движение».

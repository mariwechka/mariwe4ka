# NOCTURNE — магазин виниловых пластинок

Сайт независимого магазина винила: интернет-магазин с подачей музыкального журнала.
Чистые HTML / CSS / JavaScript, без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере (двойной клик): всё работает без сервера.
Для разработки удобнее локальный сервер:

```bash
cd nocturne
python3 -m http.server 8000   # → http://localhost:8000
```

## Что внутри

| Раздел | Адрес | Возможности |
|---|---|---|
| Главная | `#/` | Hero с проигрывателем (переключение пластинок, параллакс), новые поступления (слайдер с перетаскиванием), избранные релизы, жанры с превью обложек под курсором, коллекция недели, редакционная подборка, история, рассылка с валидацией |
| Каталог | `#/catalog` | Фильтры: жанр, исполнитель (с поиском), цена (поля + двойной ползунок), состояние, формат, наличие. Сортировка: новизна, популярность, цена ↑↓, год. Поиск, вид «сетка / список», чипы активных фильтров, «Показать ещё». Состояние фильтров хранится в URL, ссылкой можно поделиться |
| Релиз | `#/release/:id` | Обложка с выезжающей пластинкой, «поставить на проигрыватель», звук иглы (Web Audio), количество, корзина, избранное, характеристики, шкала состояния, треклист, об исполнителе, похожие альбомы, липкая панель покупки на мобильных |
| Новинки | `#/new` | Журнал поступлений по периодам |
| Коллекции | `#/collections`, `#/collection/:id` | 6 коллекций со своим цветом, «добавить всю коллекцию», переход к следующей |
| About | `#/about` | Манифест, принципы, оценка состояния винила, команда, адрес |
| Корзина | панель + `#/cart` | Количество (с учётом остатка), удаление, бесплатная доставка от 7 000 ₽, итог |
| Оформление | `#/checkout` → `#/order/:no` | Валидация полей, способы доставки, оформление заказа уменьшает остаток |
| Избранное | `#/favorites` | Список, удаление, «всё доступное в корзину» |
| Поиск | `/` или иконка | Мгновенный поиск по альбому, исполнителю, жанру, лейблу; навигация стрелками |

**Детали интерфейса:** заставка при первом входе, шторки-переходы между страницами, курсор с подсказками («Открыть», «Тянуть»), мега-меню каталога, быстрый просмотр товара, блок «Вы смотрели», анимация заголовков по словам, индикатор прокрутки, бегущая строка, реагирующая на скролл. На конвертах б/у видны потёртости, зависящие от грейда. При включённой в системе настройке «уменьшить движение» анимации отключаются.

Корзина, избранное и заказы сохраняются в `localStorage` и синхронизируются между вкладками.

## Структура

```
index.html          оболочка: шапка, меню, панель корзины, поиск, таб-бар
css/base.css        токены (цвета, шрифты), типографика, кнопки, анимация появления
css/layout.css      шапка, мобильное меню, панели, футер, переходы страниц
css/components.css  пластинка, карточка, строка списка, слайдер, элементы форм
css/pages.css       композиции страниц и адаптивность
css/fx.css          заставка, шторки, курсор, мега-меню, быстрый просмотр
js/utils.js         вспомогательные функции
js/data.js          каталог: релизы, исполнители, жанры, коллекции
js/cover.js         генеративные обложки (SVG)
js/store.js         состояние: корзина, избранное, заказы (pub/sub + localStorage)
js/components.js    переиспользуемые компоненты
js/ui.js            глобальный интерфейс: панель корзины, поиск, мега-меню, быстрый просмотр, уведомления
js/fx.js            движение: заставка, курсор, прогресс прокрутки, анимация заголовков
js/router.js        hash-роутер с переходами
js/pages/*.js       страницы
js/app.js           запуск и делегирование событий
```

## Дальнейшее развитие

- **Бэкенд.** `N.data` — единственный источник данных. Замените массивы в `js/data.js`
  ответом API той же формы; `N.store.placeOrder` — место для запроса на создание заказа.
- **Настоящие обложки.** В `components.js → sleeve()` замените `N.cover.svg(p)` на `<img>` из поля товара.
- **Оплата.** Сейчас способ «Ссылка на оплату» только фиксирует выбор; карточные данные сайт не собирает.

Исполнители, лейблы и релизы в демо-каталоге вымышлены.

# NEXUS Freelance Agent

Персональный менеджер по поиску клиентов для Мари (mariwechka.org). Работает на вашем компьютере или сервере,
без Claude Code: ищет площадки и заказы, оценивает их, готовит отклики на основе вашего реального портфолио, ведёт CRM,
помогает в переговорах и пишет в Telegram, когда клиент готов заказать.

## Запуск (один клик)
- **macOS**: двойной клик по `NEXUS.command` (первый запуск ставит зависимости, ~1 мин). Ярлык на рабочий стол: `./install-shortcut.sh`.
- **Windows**: двойной клик по `start.bat`. Ярлык: правый клик по `install-shortcut.ps1` → «Выполнить с PowerShell».
- **Linux**: `./start.sh`, ярлык: `./install-shortcut.sh`.
- **Docker / сервер**: `cp .env.example .env` → `docker compose up -d` → http://127.0.0.1:8765

Нужен Python 3.10+. Интерфейс открывается сам: http://127.0.0.1:8765. Агенты работают, пока запущено приложение
(вкладку браузера можно закрыть). Чтобы работать 24/7 при выключенном компьютере — запустите Docker-версию на VPS
(сервер не покупается автоматически).

## Первая настройка (10 минут)
1. **Настройки → API keys**: вставьте `ANTHROPIC_API_KEY` — без него агенты ищут и оценивают заказы, но не пишут
   персональные отклики (по кнопке доступен черновик-скелет).
2. **Telegram**: создайте бота у @BotFather, вставьте токен, отправьте боту с @mrwechka `/start <код>` из Настроек.
3. **Gmail** (по желанию): см. `INTEGRATIONS.md` → кнопка «Connect Gmail». Пароль Google не нужен (OAuth).
4. **Портфолио → Недостающие данные**: ответьте один раз (страна, языки и уровень, цены по услугам, способы вывода…).
   Пока цены не заданы, агенты не называют стоимость.
5. Режим по умолчанию — **Ручной**: всё внешнее требует вашего подтверждения. Smart/Full Autopilot — в меню слева.

## Как пользоваться каждый день
- **Обзор** — сводка, лучшие заказы, события. **Заказы** — все найденные заказы с рейтингом и объяснением.
- **Отклики** — готовые тексты: «Копировать и открыть заказ» → вставить на площадке → «Отмечено как отправлено».
- **Клиенты** — CRM (перетаскивание между 13 этапами). Ответ клиента с площадки вставьте в карточку — агент
  переговоров определит намерение, предложит ответ и передвинет клиента по воронке. «Найти бизнесы» — поиск
  кафе/салонов/… в городе с аудитом их сайтов.
- **Подтверждения** — письма к отправке, регистрации, карточки сделок (Принять / Отклонить / Изменить цену…).
- **Аварийная остановка** (слева внизу или `/stop` в Telegram) мгновенно блокирует все внешние действия.

## Что автоматизировано, а что нет (честно)
| Автоматически | Вручную (агент готовит всё, вы нажимаете) |
|---|---|
| поиск и проверка площадок, поиск заказов (Freelancer, FL.ru, Freelancehunt, Remote OK, WWR, Telegram-каналы, RSS) | регистрация (CAPTCHA, SMS, документы, принятие условий) |
| оценка, фильтрация, мошенники, дубликаты | отправка откликов на биржах (их правила запрещают ботов или нет API) |
| тексты профилей, услуг (Basic/Standard/Premium), откликов | публикация профилей и услуг |
| письма бизнесам, ответы клиентам по email (Smart/Full + лимиты) | принятие заказа, финальная цена, сроки, договор, оплата |

Тесты: `pip install -r requirements-dev.txt && python -m pytest -q tests`. Документы: `ARCHITECTURE.md`, `AGENTS.md`,
`INTEGRATIONS.md`, `SECURITY.md`, `TESTING.md`, `PROGRESS.md`.
